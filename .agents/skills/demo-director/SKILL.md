# Demo Director

The demo must tell one story:

An AI agent is useful.
The agent encounters malicious context.
The agent attempts a dangerous action.
The gateway intercepts it.
The policy explains the violation.
The action is blocked.
The decision is recorded.
The system remains under human-defined control.

Never depend on:

- internet connectivity
- external APIs
- live credentials
- unpredictable model responses
- fragile third-party services

Create deterministic demo fixtures.

The one-click demo must:

1. reset environment
2. show safe request
3. execute safe request
4. inject malicious context
5. trigger unsafe tool request
6. intercept request
7. display policy violation
8. block execution
9. create audit event
10. show final security state

Target duration:
2–3 minutes.

Optimize every screen for judge comprehension.

The demo must still work if optional AI/SLM analysis is unavailable.
